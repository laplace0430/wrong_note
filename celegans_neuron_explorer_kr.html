예쁜꼬마선충 뉴런 연결 탐색기

뉴런 이름을 검색하면 해당 뉴런의 기능, 위치, 분류, 연결된 뉴런, 그리고 선택한 뉴런을 포함하거나 통과하는 감각→개재→운동 뉴런 관계를 한 화면에서 확인할 수 있습니다. WormAtlas, WormWeb, WormImage의 탐색 방식을 참고한 교육용 인터페이스이며, 아래 데이터셋은 주요 뉴런 중심의 축약 샘플입니다.

302성체 암수동체 C. elegans의 대표적 뉴런 수
3주요 기능 층위: 감각 뉴런, 개재 뉴런, 운동 뉴런
확장형전체 connectome JSON 또는 CSV를 붙이면 302개 뉴런으로 확장 가능
주의: 실제 연결 강도와 시냅스 수는 데이터셋과 재주석 버전에 따라 달라질 수 있습니다. 본 화면은 학습·발표용 축약 모델입니다.

데이터 확장 방식

전체 302개 뉴런으로 확장하려면 아래와 같은 노드·엣지 배열을 추가하면 됩니다.

nodes.push({ id: "PVCL", label: "PVCL", role: "interneuron", region: "tail / ventral cord", summary: "좌측 PVC command interneuron", functions: ["전진 운동 회로 조절", "후방 촉각 정보 통합"] }); edges.push({ from: "PLM", to: "PVCL", type: "chemical", weight: 4, note: "후방 촉각 입력의 축약 예시" });
